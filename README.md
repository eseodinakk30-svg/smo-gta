# San Monica: Saltwater Debt

Полноценная 3D игра с открытым миром для Android на **Unity 6 LTS + URP + C#**.
Город San Monica — **16 × 16 км (268 км²)**: центр с небоскрёбами, жилые кварталы,
богатые холмы, промзона, порт, аэропорт, пригороды, фермы, лес, горы, пустыня,
пляж и океан. Мир, транспорт, персонажи, звук и музыка **генерируются процедурно
в рантайме**, поэтому репозиторий не содержит ни одного заимствованного ассета.

> Игра оригинальная. GTA V использовалась только как ориентир по масштабу и типу
> механик. Все названия, персонажи, сюжет, машины, оружие, музыка и текстуры —
> собственные.

## 1. Что нужно для сборки APK

## 2. Сборка APK — пошагово (самый простой путь)

1. **Установите Unity Hub** → вкладка *Installs* → *Install Editor* → версия
   **6000.0.32f1** → в списке модулей отметьте **Android Build Support**, а внутри
   него — **Android SDK & NDK Tools** и **OpenJDK**.
2. **Склонируйте репозиторий**:
   ```bash
   git clone https://github.com/eseodinakk30-svg/smo-gta.git
   cd smo-gta
   ```
3. **Откройте проект**: Unity Hub → *Add* → выберите папку `smo-gta` → откройте.
   При первом открытии Unity импортирует пакеты (5–15 минут) и автоматически
   выполнит настройку проекта: создаст четыре URP-ассета качества, настроит
   Android Player Settings, оси геймпада и сцену `Assets/Scenes/Boot.unity`.
   *Если что-то не применилось — меню **San Monica → Setup Project**.*
4. **Проверьте, что игра запускается**: откройте `Assets/Scenes/Boot.unity`
   и нажмите **Play**. Игра собирает мир сама — экран загрузки, затем город.
5. **Соберите APK**: меню **San Monica → Build → Android APK**.
   Готовый файл появится в `Builds/SanMonica.apk`.
6. **Установите на телефон**:
   ```bash
   adb install -r Builds/SanMonica.apk
   ```
   Или просто скопируйте `.apk` на устройство и откройте его.

### AAB для Google Play

Меню **San Monica → Build → Android App Bundle (AAB)** → `Builds/SanMonica.aab`.

### Сборка из командной строки

```bash
# APK
"/path/to/Unity/Editor/Unity" -batchmode -quit -nographics \
  -projectPath "$(pwd)" \
  -executeMethod SanMonica.EditorTools.BuildScript.BuildApk \
  -outputPath "$(pwd)/Builds/SanMonica.apk" \
  -logFile build.log

# AAB
"/path/to/Unity/Editor/Unity" -batchmode -quit -nographics \
  -projectPath "$(pwd)" \
  -executeMethod SanMonica.EditorTools.BuildScript.BuildAab \
  -outputPath "$(pwd)/Builds/SanMonica.aab" \
  -logFile build.log
```

Дополнительные аргументы: `-development`, `-versionCode 5`,
`-keystore /path/key.keystore -keystorePass … -keyalias … -keyaliasPass …`.

### Подпись релизной сборки

1. `Edit → Project Settings → Player → Publishing Settings → Keystore Manager`
   → создайте keystore и alias.
2. Либо передайте keystore аргументами командной строки (см. выше).
3. Для Google Play обязателен **AAB**, для установки напрямую — **APK**.

### Сборка в GitHub Actions

`.github/workflows/android-build.yml` собирает APK/AAB через
[GameCI](https://game.ci). Добавьте секреты репозитория:
`UNITY_LICENSE`, `UNITY_EMAIL`, `UNITY_PASSWORD` и, для подписи,
`ANDROID_KEYSTORE_BASE64`, `ANDROID_KEYSTORE_NAME`, `ANDROID_KEYSTORE_PASS`,
`ANDROID_KEYALIAS_NAME`, `ANDROID_KEYALIAS_PASS`.
Запуск: вкладка *Actions* → *Android Build* → *Run workflow*.

## 4. Управление

**Сенсор.** Слева — плавающий стик движения, справа — зона обзора и прицеливания.
Кнопки меняются в зависимости от контекста (пешком / за рулём): огонь, прицел,
прыжок, бег, присесть, перезарядка, удар, газ, тормоз, ручник, сигнал, радио,
сесть/выйти, взаимодействие, смена оружия, камера, карта, пауза.
Размер, прозрачность, положение кнопок и чувствительность настраиваются
в **Настройках** (в том числе режим перетаскивания кнопок).

**Bluetooth-геймпад** поддерживается: левый стик — движение, правый — камера,
триггеры — газ/тормоз и огонь/прицел, кнопки — прыжок, взаимодействие, посадка.

**Клавиатура (в редакторе).** WASD, мышь, ЛКМ — огонь, ПКМ — прицел,
Space — прыжок/ручник, Shift — бег, C — присесть, R — перезарядка, F — сесть/выйти,
E — взаимодействие, Q — смена оружия, T — вид от первого лица, M — карта,
N — радио, Esc — пауза.

## 5. Что уже работает

**Мир**
- Аналитический ландшафт 16 × 16 км: побережье, залив Halcyon, река Redwater,
  холмы Crestwood, горы Mount Cinder, пустыня Dry Wash, пляжи и морское дно.
- 18 типов районов со своей архитектурой, освещением, плотностью людей,
  трафиком, присутствием полиции и уровнем преступности.
- Дорожная сеть: уличная сетка, авеню, три автострады, сельские и грунтовые
  дороги, полосы, разметка, тротуары, бордюры, светофоры, ВПП аэропорта.
- Один детерминированный проход планировки создаёт ~15 000 участков застройки,
  сотни магазинов, покупаемую недвижимость и парковочные места на всю карту.
- Здания: небоскрёбы с отступами и мачтами, офисы, кирпичные многоэтажки
  с балконами, частные дома с гаражами и крыльцом, виллы с бассейнами, склады,
  терминалы и ангары, фермы с силосами, пляжные пастельные дома, хижины.
- Реквизит: фонари, светофоры, деревья (лиственные, сосны, пальмы, кусты, сухие),
  скамейки, урны, гидранты, паркоматы, остановки, вывески, билборды, заборы,
  контейнеры, портовые краны, ЛЭП, заправочные колонки, навесы, скалы, пирсы.

**Бесшовный стриминг**
- Чанки 256 м, три уровня детализации, сборка по бюджету кадра, пулы объектов.
- Пул уличных фонарей, включающихся ночью рядом с игроком.
- Запечённый дальний ландшафт и силуэт города на горизонте — без загрузочных
  экранов при обычном перемещении.

**Персонаж**
- Процедурный скелет из 19 костей, skinned mesh, упрощённый меш для дальнего LOD.
- Анимация в стиле blend tree: ходьба, бег, спринт, присед, прыжок, падение,
  плавание, ныряние, лазание, вождение, прицеливание, отдача, удары, реакции.
- Физический рагдолл, он же иерархия хитбоксов: хедшоты и попадания по конечностям.
- Здоровье, броня, утопление, урон от падения.

**Транспорт (46 машин)**
- Седаны, купе, спорткары, суперкары, маслкары, внедорожники, пикапы, фургоны,
  грузовики, автобусы, такси, полиция, скорая, пожарная, эвакуатор, мусоровоз,
  трактор, погрузчик, мотоциклы, скутер, кроссовый мотоцикл, лодки, катера,
  яхта, буксир, гидроцикл, три вертолёта, три самолёта, бронемашина.
- Физика: WheelCollider с антикреном и заносом на ручнике, наклоняющиеся
  мотоциклы, лодки на выталкивающей силе, вертолёты с общим шагом, самолёты
  с подъёмной силой; повреждения, взрывы, наезды на людей, сирены, фары.

**Живой город**
- Трафик: следование по полосам, светофоры, торможение, обгон, паника,
  парковка, спавн вне поля зрения, плотность по району и времени суток.
- 23 архетипа NPC: горожане, рабочие, докеры, торговцы, студенты, туристы,
  бегуны, механики, охрана, полиция, спецназ, медики и три банды.
- ИИ: зрение с конусом обзора (хуже ночью и в дождь), слух по событиям,
  состояния (бродить, работать, бежать, прятаться, звонить в полицию, искать,
  драться, ехать, сдаваться), отношения фракций.
- AI LOD: до 50 м полный ИИ, до 150 м упрощённый, дальше — дешёвая симуляция.

**Полиция**
- 5 уровней розыска, свидетели, эвакуация по времени и потере из виду.
- Патрули, перехватчики, спецназ, блокпосты, вертолёт с облётом, арест.

**Бой**
- 18 видов оружия: кулаки, бита, разводной ключ, мачете, пистолеты, ПП,
  дробовики, автоматы, снайперская винтовка, пулемёт, РПГ, гранаты, коктейли.
- Разброс, отдача, дробь, бронебойность, магазины, перезарядка, урон по зонам,
  трассеры, вспышки, декали, кровь, взрывы с уроном по площади.

**Прогресс**
- Сюжет «Saltwater Debt»: 15 миссий в 5 главах, оригинальные персонажи —
  Доминик Вела, Рук Кастельянос, Айви Марлоу, Талия Рейес, Тере Бастида,
  Арден Восс; фракции: SMPD, картель Серрано, синдикат Iron Bay,
  Halcyon Dynamics, Vanguard Security, Calle Nueve.
- 5 повторяемых побочных занятий: такси, гонки, изъятие машин, контракты, эскорт.
- 19 типов целей миссий с настоящей логикой, таймерами и провалом.
- Случайные события: ограбления, перестрелки банд, поломки, сделки, аварии.
- Экономика, 18 типов магазинов с настоящими покупками, интерьеры,
  недвижимость с доходом, гараж с апгрейдами и доставкой машин.

**Атмосфера**
- Цикл суток, влияющий на трафик, людей, работу магазинов и полицию.
- Погода: ясно, облачно, пасмурно, дождь, гроза с молниями, туман, жара —
  со влиянием на видимость, сцепление, звук и освещение.
- Вода: море, залив, река; волны, плавание, ныряние, лодки, подводная камера.

**Звук**
- Весь звук синтезируется кодом: двигатели по параметрам машины, выстрелы,
  сирены, сигналы, шаги, удары, взрывы, дождь, ветер, гром, город.
- 8 оригинальных радиостанций, которые сами сочиняют треки (ударные, бас,
  аккорды, лид) в фоновом потоке, с ведущими, новостями и рекламой.

**Интерфейс**
- HUD, миникарта с поворотом, полноэкранная карта всего города с маршрутными
  точками, магазины, пауза, настройки, 3 слота сохранений + автосейв.
- Качество Low / Medium / High / Ultra + **Auto Quality**, профилирование
  устройства, ручные ползунки дальности, плотности и FPS.

## 7. Производительность

| Класс устройства | Пресет | Цель |
|---|---|---|
| Слабое (2–3 ГБ RAM) | Low | 30 FPS, render scale 0.62, 1 каскад теней |
| Среднее (4–6 ГБ) | Medium | 45 FPS, render scale 0.80 |
| Мощное (8 ГБ) | High | 60 FPS, render scale 1.0, мягкие тени |
| Флагман (12 ГБ+) | Ultra | 60 FPS, render scale 1.1, дальность ×1.45 |

Пресет выбирается автоматически по профилю устройства, **Auto Quality** держит
целевой FPS, меняя детализацию — **контент при этом не удаляется**: масштабируются
только дальность прорисовки, плотность симуляции и качество эффектов.

Ключевые приёмы: SRP Batcher, GPU instancing, палитровый атлас (персонаж или
машина рисуются 1–5 вызовами отрисовки), объединение геометрии чанка в один меш,
box-коллайдеры вместо mesh-коллайдеров для зданий, пулы объектов, AI LOD,
время-слайсинг генерации, ограниченный пул динамических источников света.

Подробности, таблица пресетов и честный разбор того, что сделано иначе, чем в
классическом пайплайне (occlusion culling, лайтмапы, Addressables) —
в [`docs/OPTIMIZATION.md`](docs/OPTIMIZATION.md).

## 8. Ассеты и лицензии

Проект **не содержит** сторонних моделей, текстур, звуков или музыки.
Всё создаётся кодом при запуске:

- меши — `Utils/MeshBuilder` и процедурные фабрики;
- текстуры — `Utils/TextureFactory` (альбедо + производные карты нормалей);
- звук — `Audio/ProceduralAudio` (синтез);
- музыка — `Audio/MusicSynth` (оригинальные композиции);
- шрифт — встроенный шрифт Unity.

Материалы из GTA V или других коммерческих игр не используются.
Код проекта распространяется по лицензии Apache 2.0 (см. `LICENSE`).

## 9. Тестирование

Весь рантайм-код типизированно проверяется автоматически (см. раздел 3) —
на текущей ревизии **0 ошибок и 0 предупреждений**, и это же проверяет CI.
Такая проверка ловит ошибки кода, но не заменяет запуск: чек-лист того, что
нужно один раз пройти в редакторе и на устройстве, лежит
в [`docs/TESTING.md`](docs/TESTING.md).

## 10. Если что-то пошло не так

| Симптом | Решение |
|---|---|
| Всё розовое / нет материалов | Меню **San Monica → Setup Project**, затем перезапуск редактора |
| «No scenes in build settings» | То же меню — оно создаёт `Boot.unity` и добавляет её в билд |
| Android SDK не найден | Unity Hub → *Installs* → шестерёнка → *Add modules* → Android SDK & NDK Tools |
| Долгая первая загрузка в игре | Нормально: генерируются планировка города и дальний ландшафт |
| Низкий FPS | Настройки → включите **Auto Quality** или выберите Low/Medium |
| Игра не стартует в пустой сцене | Она стартует из любой сцены; проверьте, что скрипты скомпилировались |

## 11. Дальнейшее развитие

Готовая база позволяет наращивать контент без изменения архитектуры:
новые машины и оружие — это одна запись в каталоге; новые миссии — запись
в `StoryCatalog`; новые районы — якорь в `WorldMap`. Для очень больших наборов
внешних ассетов в проект уже заложены точки подключения Addressables
(пакет установлен) и Play Asset Delivery.
