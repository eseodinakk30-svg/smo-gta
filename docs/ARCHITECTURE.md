# Архитектура San Monica

Unity 2022.3 LTS + URP 14, C#, Android.

## Принцип

Игра **собирает себя во время выполнения**. В репозитории нет ни одного
бинарного ассета: мир, машины, персонажи, текстуры, звук и музыка создаются
кодом из данных. Это даёт три вещи сразу — репозиторий остаётся лёгким,
контент не имеет лицензионных ограничений, а мир может быть сколь угодно
большим, потому что он описывается формулой, а не файлами.

## Слои

```
GameBootstrap  →  GameManager  →  Services  →  системы
```

- **GameBootstrap** — `[RuntimeInitializeOnLoadMethod]`. Создаёт корневой объект
  и запускает загрузку из любой сцены.
- **GameManager** — корутина загрузки, состояния игры (Playing, Paused, InMenu,
  Cutscene, Dead, Busted, Shopping), магазины, интерьеры, смерть и арест.
- **Services** — плоский локатор ссылок на все системы. Заполняется один раз при
  загрузке, чтобы в кадре не было ни одного `GetComponent` или `Find`.
- **GameEvents** — статическая шина событий: преступления, шум, розыск, деньги,
  миссии, погода, час, взрывы. Системы не держат ссылок друг на друга.

## Порядок инициализации

1. Конфиг мира, пулы, база данных контента
2. Качество, профилировщик, звук, ввод, сохранения, интерфейс
3. Камера
4. Карта мира → сетка районов → дорожная сеть → планировка города
5. Ориентиры, навигация
6. Время, погода, небо, вода, интерьеры
7. Стриминг чанков
8. Фабрики транспорта, NPC, оружия, эффектов
9. Население, AI LOD, трафик, розыск, полиция
10. Экономика, магазины, недвижимость, гараж, диалоги, миссии, события, радио
11. Игрок → предзагрузка чанков → дальний мир → применение настроек

## Детерминизм

Всё содержимое мира — чистая функция от `WorldConfig.seed`:

```
seed → WorldMap (высоты, побережье, районы)
     → RoadNetwork (улицы, авеню, автострады)
     → CityLayout (участки, магазины, недвижимость, парковки)
     → ChunkBuilder (геометрия чанка)
```

Поэтому сохранение хранит только прогресс — позицию, деньги, оружие, миссии,
недвижимость и гараж. Геометрия восстанавливается из зерна.

## Бюджеты кадра

- `FrameBudget` — генерация чанков не выходит за отведённые миллисекунды.
- `RoundRobinScheduler` — дорогие пообъектные апдейты (AI LOD, трафик)
  распределяются по кадрам.
- `ProceduralAnimator.UpdateInterval` — дальние NPC анимируются реже.
- `PopulationManager` / `TrafficManager` — спавн и удаление вне поля зрения.

## Отрисовка

| Что | Приём | Результат |
|---|---|---|
| Чанк мира | один меш, сабмеши по материалам | ~5–15 draw calls на чанк |
| Персонаж | палитровый атлас, один материал | 1 draw call |
| Машина | палитровый атлас, 3–5 материалов | 3–5 draw calls |
| Здания | box-коллайдеры вместо mesh | дешёвая физика |
| Дальний мир | запечённый ландшафт + силуэт | 2 draw calls на горизонт |

`PaletteAtlas` — ключевой приём: 256 цветов в одной текстуре, UV каждой детали
указывают на нужную ячейку. Уникальный вид без уникальных материалов.
