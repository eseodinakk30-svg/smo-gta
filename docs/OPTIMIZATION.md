Стартовый пресет выбирается по профилю устройства (RAM, VRAM, ядра, уровень
шейдеров, разрешение экрана). **Auto Quality** каждые 4 секунды сравнивает
фактический FPS с целевым и переключает пресет: ниже 82 % — понижает,
выше 108 % четыре раза подряд — повышает.

Важно: понижение качества **не удаляет контент**. Город, миссии, машины, оружие
и NPC остаются те же — меняются дальность прорисовки, плотность симуляции,
разрешение текстур и качество эффектов.

## Основные приёмы

**Отрисовка**
- SRP Batcher включён во всех четырёх URP-ассетах.
- GPU instancing включён на всех материалах.
- `PaletteAtlas` — 256 цветов в одной текстуре: персонаж рисуется одним вызовом,
  машина — тремя-пятью, при этом каждый выглядит по-своему.
- Геометрия чанка объединяется в один меш с сабмешами по материалам:
  улица с сотнями объектов стоит 5–15 draw calls вместо тысяч.
- Дальний мир — один запечённый меш ландшафта и один меш силуэта города.
- Скиннинг в одну кость (`SkinWeights.OneBone`), упрощённый меш для дальних NPC.

**Физика**
- Здания — box-коллайдеры, сгруппированные по повороту на одном GameObject,
  а не mesh-коллайдеры.
- MeshCollider только на ландшафте ближних чанков (LOD 0–1).
- Слой `Ragdoll` не сталкивается ни с чем: хитбоксы служат только для рейкастов,
  пока персонаж жив.
- Дальний трафик переводится в Discrete collision detection.
- `Time.fixedDeltaTime = 1/50`, 6 итераций солвера.

**Симуляция**
- AI LOD: полный ИИ / упрощённый / грубая симуляция по расстоянию.
- Пешеходы и трафик спавнятся вне поля зрения и переиспользуются из пулов.
- Дорогие апдейты распределяются по кадрам через `RoundRobinScheduler`.
- Генерация чанков ограничена бюджетом кадра (`FrameBudget`).
- Пул уличных фонарей: включается ограниченное число ближайших ламп ночью.

**Память**
- Мир не хранится в ассетах — он функция от зерна, поэтому APK остаётся малым.
- Текстуры генерируются, сжимаются и помечаются non-readable.
- Сохранение — только прогресс, геометрия восстанавливается из зерна.
- Пулы подрезаются, ушедшие чанки освобождают меши и коллайдеры.

## Что сделано иначе, чем в «классическом» пайплайне, и почему

| Классический приём | Здесь | Причина |
|---|---|---|
| Occlusion Culling (запечённый) | frustum culling + чанковый LOD + туман + слияние геометрии | Запекание требует статичной сцены; мир генерируется в рантайме |
| Baked lightmaps / light probes | реалтайм-солнце с каскадами + trilight ambient, привязанный к времени суток | Лайтмапы нельзя запечь для процедурной геометрии |
| Reflection probes | смусенность материалов + отражения неба; вода — прозрачный слой с волнами | Пробы требуют запекания или дорогих реалтайм-обновлений |
| Addressables / AssetBundles | процедурная генерация из зерна | Нет внешних ассетов, которые нужно было бы стримить; пакет установлен и точки подключения оставлены |
| Импортированные модели и анимации | процедурные меши и код-анимация | Нужен полностью оригинальный, свободный от лицензий контент |

Если в проект позже добавятся импортированные ассеты, Addressables и Play Asset
Delivery подключаются поверх существующего `ChunkStreamer` без изменения его
архитектуры: он уже работает с абстракцией «построить содержимое чанка».
