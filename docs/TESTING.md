# Проверки и что нужно проверить на устройстве

## Что проверено автоматически

**Типизация всего рантайм-кода.** `tools/compilecheck` содержит stub-сборку
Unity API и проект, который компилирует **все** скрипты из `Assets/Scripts`
(кроме редакторных) обычным C#-компилятором:

```bash
dotnet build tools/compilecheck/CompileCheck.csproj
```

Результат: `0 Errors, 0 Warnings`. Это ловит опечатки, несовпадение сигнатур
между системами, отсутствующие using и ошибки в перекрёстных ссылках — то есть
всё, что иначе всплыло бы только при открытии проекта в Unity.
Тот же прогон выполняется в CI на каждый push
(`.github/workflows/compile-check.yml`).

## Чего проверка не заменяет

Stub-сборка описывает Unity API, но не исполняет его. Поэтому **обязательно**
нужно один раз пройти следующий чек-лист в редакторе и на устройстве.

### В редакторе (Play Mode)

- [ ] Проект открывается, `San Monica → Setup Project` отрабатывает без ошибок
- [ ] `Assets/Scenes/Boot.unity` → Play: проходит экран загрузки, появляется город
- [ ] Персонаж ходит, бежит, прыгает, приседает, перелезает, плавает, ныряет
- [ ] Камера от третьего и первого лица, прицеливание, столкновения камеры
- [ ] Посадка в машину, вождение, выход; мотоцикл, лодка, вертолёт, самолёт
- [ ] Трафик едет по полосам и останавливается на светофорах
- [ ] Пешеходы ходят, разбегаются от выстрелов, вызывают полицию
- [ ] Стрельба: попадания, хедшоты, рагдолл, декали, кровь, гранаты
- [ ] Розыск: звёзды растут, приезжают патрули, вертолёт с 3 звёзд, арест
- [ ] Миссия у маркера запускается, цели сменяются, награда начисляется
- [ ] Магазин открывается интерьером, покупки применяются
- [ ] Покупка недвижимости, отдых, доход; гараж выдаёт машину
- [ ] Карта рисуется, миникарта поворачивается, маршрутная точка ставится
- [ ] Сохранение в слот и загрузка возвращают позицию, деньги, оружие, прогресс
- [ ] Смена времени суток и погоды видна на освещении, звуке и дорогах
- [ ] Радио играет, станции переключаются, ведущий и новости появляются

### На Android

- [ ] APK ставится и запускается на устройстве с Android 7.0+
- [ ] Тач-управление отзывчиво, кнопки настраиваются и сохраняются
- [ ] Bluetooth-геймпад управляет игрой
- [ ] FPS: 30 на слабом, 45 на среднем, 60 на мощном устройстве
- [ ] Auto Quality понижает и повышает пресет при просадках
- [ ] Нет утечек памяти при долгой езде по городу (следить за `Managed MB`
      в статистике на паузе)
- [ ] Нет заметного нагрева при 20 минутах игры на среднем пресете
- [ ] Разные соотношения сторон (16:9, 18:9, 20:9, планшет 4:3) — интерфейс не режется

## Встроенная статистика

Экран паузы показывает живую сводку: FPS и время кадра, управляемая память,
число загруженных и очередных чанков, количество пешеходов с разбивкой по AI LOD,
количество машин трафика и припаркованных машин, главу, миссии, деньги,
недвижимость и коллекцию машин. Этого достаточно, чтобы находить просадки без
подключения профайлера.
